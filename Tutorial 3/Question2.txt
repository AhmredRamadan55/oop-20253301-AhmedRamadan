Tutorial Session — Question 2

Trace the code and compare while and do-while.

Part A: while loop
int x = 10;
while (x < 5) {
    System.out.print("While ");
    x++;
}

Initial value: x = 10
Condition: 10 < 5 is false, so the loop body executes zero times.
Output: Nothing.

Part B: do-while loop
int y = 10;
do {
    System.out.print("Do-While ");
    y++;
} while (y < 5);

The do block executes before the condition is checked. It prints "Do-While ", then y becomes 11. The condition 11 < 5 is false, so the loop stops.
Output: Do-While 

Difference:
- A while loop checks its condition before the body, so it may execute zero times.
- A do-while loop checks its condition after the body, so it executes at least once.
