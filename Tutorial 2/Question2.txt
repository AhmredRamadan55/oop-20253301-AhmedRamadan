Lab Sheet 2 — Tutorial, Question 2

Explain the difference

Two separate if statements:
if (x > 0) y++;
if (x < 0) y--;

These are independent if statements. Each condition is checked separately. For an integer x, the conditions are mutually exclusive, so at most one statement executes.

One if / else-if chain:
if (x > 0) y++;
else if (x < 0) y--;

These conditions form one decision chain. Once a condition is true, any remaining else-if conditions are skipped. If x is 0, neither statement executes.
